# Betreuungsplatz-Finder

Prototyp zur Idee «Betreuungsplätze einfach finden» aus dem Konzept Vereinbarkeit live: Suche über Filter, Karte von Liechtenstein, Wochenraster pro Tag und Online-Reservation.

**Wichtig:** Die Einrichtungen entsprechen dem Verzeichnis auf familienportal.li (Stand 25.11.2026). Freie Plätze, Öffnungszeiten und Altersgrenzen sind erfundene Demo-Daten. Es werden keine Daten gesendet.

Eine einzelne Datei (`index.html`) ohne Build-Schritt. Umrisse der Karte: © OpenStreetMap-Mitwirkende (ODbL), vereinfacht.
